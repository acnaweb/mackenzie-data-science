# 📘 DISCIPLINA: Data Science Experience

## 🧾 Carga Horária
32 horas (8 semanas)

---

## 📌 Ementa

Explorar os fundamentos de Ciência de Dados com base em análise estatística e aprendizagem de máquina aplicada a problemas reais. A disciplina aborda desde o entendimento do problema de negócio até a construção, avaliação e interpretação de modelos preditivos, incluindo práticas modernas como AutoML e visão introdutória de MLOps.

---

## 🎯 Objetivo Geral

Capacitar o aluno a compreender e aplicar técnicas de Data Science para resolver problemas reais de negócio, utilizando análise estatística, machine learning e interpretação de resultados.

---

## 🎯 Objetivos Específicos

- Entender o ciclo de vida de projetos de Data Science (CRISP-DM)
- Realizar análise exploratória de dados (EDA)
- Aplicar conceitos de estatística em dados reais
- Preparar dados para modelagem (feature engineering)
- Construir modelos de machine learning supervisionados
- Avaliar modelos com métricas adequadas ao negócio
- Utilizar ferramentas de AutoML
- Gerar insights acionáveis para tomada de decisão

---

## 📚 Conteúdo Programático

### 🔹 Módulo 1 — Introdução à Data Science
- Conceitos fundamentais
- Tipos de problemas (classificação, regressão, clusterização)
- Ciclo de vida (CRISP-DM)
- Data Science no contexto de negócio

---

### 🔹 Módulo 2 — Análise Exploratória de Dados (EDA)
- Tipos de variáveis
- Estatística descritiva
- Distribuições e correlações
- Identificação de outliers e valores ausentes
- Visualização de dados

---

### 🔹 Módulo 3 — Estatística Aplicada
- Probabilidade básica
- Distribuições (Normal, Binomial)
- Testes de hipótese
- Intervalo de confiança
- Aplicação prática em datasets reais

---

### 🔹 Módulo 4 — Preparação de Dados (Feature Engineering)
- Tratamento de dados faltantes
- Encoding de variáveis categóricas
- Normalização e padronização
- Criação de novas features
- Data leakage

---

### 🔹 Módulo 5 — Machine Learning (Supervisionado)
- Regressão Linear
- Regressão Logística
- Árvores de decisão
- Random Forest
- Gradient Boosting (XGBoost / LightGBM)

---

### 🔹 Módulo 6 — Avaliação de Modelos
- Métricas:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - ROC-AUC
- Overfitting vs Underfitting
- Cross-validation

---

### 🔹 Módulo 7 — AutoML e Aceleração
- Conceitos de AutoML
- Ferramentas (Auto-sklearn, H2O, Vertex AI)
- Comparação com modelos tradicionais

---

### 🔹 Módulo 8 — Projeto Final e Visão de Produção
- Pipeline de Data Science
- Introdução ao MLOps
- Deploy conceitual
- Storytelling com dados
- Geração de insights de negócio

---

## 🧩 Metodologia

- Aulas expositivas com foco prático
- Desenvolvimento de projeto ao longo do curso
- Uso de dataset real (Telco Customer Churn)
- Exercícios guiados com aplicação direta
- Discussão de casos de uso reais

---

| Critério | Peso |

## 🚀 Diferenciais da Disciplina

- Abordagem orientada a problemas reais de negócio
- Foco em dados tabulares (cenário predominante no mercado)
- Introdução a AutoML e MLOps
- Desenvolvimento de pensamento analítico e crítico
- Preparação para aplicação profissional imediata
